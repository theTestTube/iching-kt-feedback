# Fuxi's Eight Gates: feedback

This is where testers of the **Fuxi's Eight Gates** app (伏羲八門) send bug reports and
suggestions. It holds issues only. There is no code here.

## How to give feedback

1. **Email first:** write to [feedback@thetesttube.org](mailto:feedback@thetesttube.org).
   You don't need a GitHub account for this.
2. **Or open an issue here** if you have a GitHub account. Choose
   [New issue](https://github.com/theTestTube/iching-kt-feedback/issues/new/choose), then pick the *Bug report* or *Suggestion* form.

A bug report helps us most when it includes the app version, your device model, the Android
version, and the steps that make the problem happen.

## Quoting text from the app

Quote in-app text only briefly, and only as much as you need to describe a problem. Name the
hexagram and the line (for example *"hexagram 1, line 3"*) instead of pasting passages.

The classical sources behind the app are in the public domain: James Legge's English
translation (1882) and the Chinese text of the Zhouyi 周易. The app's Spanish translations,
its commentary and the rest of its text are the project's own work, and they belong to the
proprietary app.

## Issues are public

Anyone can read what you post here. Do not post personal data: no account email addresses,
no Google Play account details, and no device identifiers (IMEI, serial number, advertising
ID and the like). If a problem can only be explained with such data, send it by email instead.
