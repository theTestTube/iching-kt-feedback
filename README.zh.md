# 伏羲八門：意見回饋

這裡是 **伏羲八門**（Fuxi's Eight Gates）應用程式的測試者回報錯誤、提出建議的地方。本儲存庫只收議題（issue），不含任何程式碼。

## 如何提供意見

1. **優先使用電子郵件：** 寄信至 [feedback@thetesttube.org](mailto:feedback@thetesttube.org)。這個方式不需要 GitHub 帳號。
2. **或在這裡開立議題**，如果你有 GitHub 帳號的話。點選 [New issue](https://github.com/theTestTube/iching-kt-feedback/issues/new/choose)（新增議題），再選擇「錯誤回報」或「建議」表單。

錯誤回報若附上應用程式版本、你的裝置型號、Android 版本，以及讓問題發生的操作步驟，對我們的幫助最大。

## 本應用程式為專有軟體

伏羲八門是專有軟體。本儲存庫並未就該應用程式、其程式碼或其內容授予任何權利。[`LICENSE`](LICENSE) 中的授權條款（CC BY 4.0）僅適用於本儲存庫的 README 檔案、議題表單及標籤設定。

## 引用應用程式中的文字

引用應用程式內的文字時，請只作簡短引用，並以描述問題所需為限。請註明卦與爻（例如 *「乾卦九三」*），不要貼上整段文字。

本應用程式所依據的古典文獻屬於公有領域：理雅各（James Legge）的英文譯本（1882 年），以及《周易》的中文原文。本應用程式的西班牙文譯文、評註及其餘文字皆為本專案的原創作品，屬於此專有應用程式。

## 議題是公開的

任何人都能閱讀你在這裡張貼的內容。請勿張貼個人資料：不要張貼帳號電子郵件地址、Google Play 帳號資料，也不要張貼裝置識別碼（IMEI、序號、廣告 ID 等）。如果問題只能靠這類資料說明，請改用電子郵件寄送。
